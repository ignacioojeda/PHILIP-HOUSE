# 💡 ESP32 3: Luz normal

## Qué controla
La luz de techo del cuarto.

## Solución
Módulo relé empotrable instalado detrás del interruptor de pared existente. El interruptor físico sigue funcionando como siempre y la luz también se controla por WiFi.

## Control
- **Voz:** "Philip, enciende la luz del cuarto".
- **App:** desde Home Assistant.
- **Manual:** el interruptor de pared de siempre.

## Materiales
- ESP32
- Módulo relé empotrable
