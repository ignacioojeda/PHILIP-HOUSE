# 🌈 ESP32 4: Luces LED y lámpara de trabajo

## Qué controla
- Luces LED de colores.
- Lámpara de trabajo.

## Solución
Un solo ESP32 maneja ambas. Antes, las luces LED iban en un enchufe inteligente WiFi; si este nodo resulta más complicado de lo que vale, el enchufe sigue siendo la alternativa simple porque no requiere tocar la instalación eléctrica.

## Control
- **Voz:** "Philip, enciende las luces de colores", "Philip, enciende la lámpara".
- **App:** desde Home Assistant.
- **Manual:** por definir.

## Materiales
- ESP32
- Luces LED de colores
- Lámpara de trabajo
