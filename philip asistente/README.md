# 🎙️ Philip, el asistente de voz

## Qué es
Asistente de voz tipo Jarvis, montado sobre Home Assistant con Home Assistant Assist y corriendo en la Raspberry Pi.

## Cómo se usa
- Control principal por voz, con comandos como "enciende la luz del cuarto" o "riega el jardín".
- La app de Home Assistant queda como segunda vía.
- Cada dispositivo conserva su control manual.
- Se puede conectar a un modelo de lenguaje para conversar de forma más natural y no solo con comandos fijos.
